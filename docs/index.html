Join in about a minute

Download the official client, then set the team number in Web Control. No account is required to start.

  1. Download the official client. Get Folding@home v8.5 for Windows, macOS, or Linux from the official download page, and run the installer. The client starts in the background when the install finishes.
  2. Open Web Control. Go to the Web Control app in your browser. Your local machine should appear after a short delay.
  3. Set team 1068033. Enter your username and team number 1068033. If you are signed in to a Folding@home Account, set them in Account Settings. If not, set them in Machine Settings.
  4. Click Fold. Your computer downloads a small piece of a real research simulation, runs it, and returns the result. Points appear after your first work unit is returned.

Get full credit: add a passkey

A passkey is not your account passphrase. A passphrase signs you in to your Folding@home Account. A passkey ties returned work units to your donor identity, and it is required for the Quick Return Bonus for fast, reliable returns.

  1. Request a passkey with your username and email. It is emailed to you.
  2. Paste it into the passkey field in Web Control. Copy and paste it, do not type it by hand, and use the same passkey on every machine you fold on.
  3. Keep it private. Never post it in a forum, chat, or public repo.

Quick Return Bonus qualification: use a passkey, successfully return at least 10 bonus eligible work units, keep an overall return rate of at least 80 percent, and return each work unit before its timeout. Bonus points are not awarded for partial returns.

Fold on your terms

In Machine Settings you control when and how hard folding runs. Start with the defaults and adjust after a first run.

Only When IdlePause folding while you use the keyboard or mouse.
CPU coresChoose how many cores Folding@home may use.
GPUsEnable or disable each GPU. GPU folding is usually much more efficient.
CausePick a preferred research area in Account Settings. Matching is attempted, not guaranteed.
Watch heat and noise first. Folding uses electricity and produces heat. Check temperatures and fan noise on a first run, lower the CPU count or pause if the machine gets too hot or loud, and do not run it unattended on a machine with cooling problems.

Advanced setup scripts

This repo also contains optional Windows and Linux setup scripts. They install the client only if it is missing, download nothing by default, back up any existing config before changing it, and never write or print a passkey or account token. Read any script in full, download it first, and run the local copy. Prefer the official installer above for a single machine.
